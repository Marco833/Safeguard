# ADR-001 : Choix du langage Python pour Safeguard

**Statut** : Accepté
**Date** : 15/09/2026
**Auteurs** :Marc, Lenny, Mouctar

## Contexte
Le projet Safeguard nécessite un langage pour développer une passerelle d'analyse
de contenu de fichiers, avec extraction de pièces jointes, calcul d'empreinte,
et journalisation. L'équipe n'a pas ou peu d'expérience en développement.

## Décision
Python a été choisi comme langage principal du projet.

## Alternatives envisagées
Aucune alternative sérieuse n'a été discutée en amont. Python s'est imposé
naturellement car c'est le langage déjà connu par les membres de l'équipe,
et le plus adapté à un projet nécessitant peu de performance brute mais
beaucoup de manipulation de fichiers et de texte.

## Conséquences
**Avantages** :
- Syntaxe simple, proche de l'anglais courant, adaptée à une équipe qui débute
- Écosystème riche : `python-magic` (détection de type), `sqlite3` (journal,
  inclus nativement), `email` (parsing de mails, inclus nativement)
- Facilite la maintenabilité et la lecture du code par les deux membres du binôme

**Limites / risques acceptés** :
- Performances plus faibles qu'un langage compilé (Go, Rust) — acceptable ici
  car le volume de mails traités reste faible dans le cadre du projet
- Nécessite un environnement virtuel (venv) pour gérer les dépendances proprement
